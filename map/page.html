What it means

Not a bug

Everything works and the tests pass. This is how one crate grows when it grows fast.

What it costs
  • A change in a foundation like settings or ports can ripple up and back down.
  • A worker can't load "just one piece", so it reads more files per item.

What I think

Good idea, and kelpie already has the data most tools have to guess at:

  • The plan: parent, slices, blocked-by.
  • What each slice touches: Touches: lists, then real diffs.
  • Where a worker is right now: phases, gates, review rounds.
The hard part

Not drawing. The galaxy shows a whole-code graph is unreadable. Each view has to be a picture the agent draws for one question, about 5 to 9 boxes. The code map stays in the background and lights up.

Prior art
  • Sourcetrail: code graph explorer, discontinued, open source.
  • CodeSee: code maps for review, closed.
  • AppMap: records what code does at runtime.
  • C4 / Structurizr: architecture at zoom levels.
  • Copilot Workspace: spec to plan to code, ended.

From memory. None of these joins a plan, a map and live agent progress the way kelpie could.

Pushback
  • Shep or kelpie? The map viewer is useful to any dog, the plan view is kelpie's.
  • Build one real case as a page first, and see if it holds your attention before building an app.
