The kelpie's two marks. `kelpie-app-icon.png` (512px) is the app icon: the face on a `brand-teal` rounded square, used whole. `kelpie-mascot.png` (1024px, transparent) is the sitting mascot for onboarding, empty states and loading, shown at 96–160px on `background`, `card` or `brand-cream`. Both are full-colour raster art with `brand-outline` ink; ask for the vector source before scaling either above its pixel size.
