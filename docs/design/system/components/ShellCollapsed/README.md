# ShellCollapsed

The shell with every panel folded to the icon strip and the drawer closed: the graph has the window.

- The icon strip is `rail-width` wide on the right, one ghost icon button per panel, each carrying that panel's NeedsYouCount.
- The closed drawer keeps its tab bar, so the process count stays visible.
- The graph's zoom level and position do not change when panels fold; it only gains room.
